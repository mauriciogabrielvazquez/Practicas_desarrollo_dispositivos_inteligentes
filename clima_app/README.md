La app es una iniciacion de proyecto y lo que muetra futter al crear un proyecto donde empezamos a cambiar texto mostrado para conocer la estructura,

Para saber que podemos crear y usar proyectos debemos ejecutar flutter doctor y despues usar flutter create para crear un proyecto y por ultimo ejecutar flutter run para ejecutar el codigo

Se espera mostar un contador en la pantalla con un boton que al presionarlo incremente, en esta practica se busca cambiar los texto y comprobar la actualizacion rapida del codigo y verlo reflejado en la pantalla
